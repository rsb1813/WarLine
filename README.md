# WarLine

2147년 베링 전선을 무대로 한 실시간 2D 대규모 전투 게임. 위에서 내려다보는 전장에서 병사 한 명을 직접 조종해 분대를 이끌고, 전차에 올라타고, 거점을 빼앗는다. 아군과 적 봇이 최대 64 대 64로 함께 싸운다.

## 실행

```bash
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
npm run build          # dist/ 에 정적 사이트 빌드
npm run build:single   # 외부 파일 없는 한 장짜리 dist/warline.html
npm test               # 엔진 테스트
npm run sim            # 봇끼리만 싸우는 전투를 화면 없이 돌려 결과 출력 (인자: easy|normal|hard)
```

## 게임 개요

- **점령전**: 거점을 더 많이 쥔 쪽이 5초마다 상대의 증원 티켓을 깎는다. 병사가 죽어도, 차량이 부서져도 티켓이 준다. 티켓이 0이 되면 진다.
- **조작**: WASD 이동, 마우스 조준과 사격, Q 장비, R 재장전, E 차량 탑승, Shift 달리기. 터치 화면에서는 왼쪽 스틱 이동, 오른쪽 스틱 조준과 자동 사격.
- **로드아웃**: 주무장 6종(돌격소총, 기관단총, 경기관총, 지정사수소총, 저격 레일건, 산탄총)과 장비 6종(수류탄, 대전차 로켓, 의무 가방, 방탄판, 수리 도구, 정찰 드론)을 골라 로드아웃을 만들고 지운다. 내 분대 네 명에게 각각 쥐여 주고, 전투 중 재배치할 때도 바꾼다.
- **분대**: 분대원 셋이 따라다니며 싸운다. 죽으면 분대원 곁, 아군 거점, 본부 가운데서 골라 다시 나온다.
- **소생**: 쓰러지면 7초 동안 의무병을 기다릴 수 있다. 일으켜 세우면 티켓이 줄지 않는다.
- **차량**: 아군 전차와 장갑차에 올라타 직접 몬다. 전차는 로켓이나 다른 전차로만 잡는다.
- **시야**: 건물, 나무, 바위는 총알과 시야를 막는다. 건물 뒤의 적은 보이지 않는다.
- **난이도**: 쉬움(기본), 보통, 어려움. 쉬움에서는 적이 느리고 부정확하며 받는 피해가 절반 이하다.
- **작전**: 진영마다 다섯 전장. 16 대 16(3.2 × 2.2 km)에서 64 대 64(6.4 × 3.8 km, 거점 일곱)까지.

## 구조

```
src/game/   전투 엔진 (화면과 무관, Node에서 그대로 실행 가능)
  data.ts      무기, 장비, 차량, 진영, 난이도, 작전 정의
  world.ts     전장 생성, 길찾기용 거리장, 시야와 충돌
  sim.ts       병사, 차량, 탄, 폭발, 거점, 티켓, 재배치
  bots.ts      봇 병사와 차량의 판단, 분대 목표 배분
  profile.ts   로드아웃과 진행 저장
src/ui/     화면
  render.ts    캔버스 렌더러와 작은 지도
  input.ts     키보드, 마우스, 터치 스틱
  audio.ts     효과음 합성
  battle.ts    전투 화면 (카메라, HUD, 배치 화면)
  screens.ts   타이틀, 작전 선택, 로드아웃, 결과, 조작 안내
tests/      엔진 테스트
scripts/    시뮬레이션, 단일 파일 빌드
```

턴제 헥스 버전은 커밋 `ea1999f`에 남아 있다.
