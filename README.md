# WarLine

2147년 베링 전선, 미 북극사령부와 러시아 극동군이 추코트카에서 맞붙는다. 위에서 내려다보는 2D 대규모 제병협동 슈터로, 병사 한 명을 직접 조종해 분대와 함께 거점을 빼앗는다. 아군과 적은 봇이 맡고 판 크기는 16 대 16부터 64 대 64까지 고른다. 한 판은 10분 안팎이다.

폰과 PC 모두에서 돌아간다. PC는 키보드와 마우스, 폰은 두 손가락 스틱과 버튼으로 조작한다.

## 실행

```bash
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
npm run build          # dist/ 에 정적 사이트 빌드
npm run build:single   # 외부 파일 없이 열리는 한 장짜리 dist/warline.html
npm test               # 엔진 테스트 (지도 생성, 길찾기, 파괴, 전투 진행, 장비, 프로필)
npm run sim            # 봇끼리만 싸우는 판을 화면 없이 돌려 결과를 찍는다
                       # 인자: 난이도(easy|normal|hard) 지도id 횟수 규모(small|medium|large)
```

## 규칙

- **점령전**: 거점을 절반 넘게 쥔 쪽이 4초마다 상대 증원 티켓을 깎는다(거점 차이만큼, 한 번에 최대 3장). 병사가 전사하면 티켓이 1장 준다. 쓰러진 병사를 의무병이 일으키면 티켓이 줄지 않는다. 티켓이 먼저 바닥나는 쪽이 지고, 14분이 지나면 티켓이 많은 쪽이 이긴다.
- **배치**: 본부, 완전히 장악한 내 편 거점, 교전 중이 아닌 분대원 곁, 분대 정찰병의 비컨, 분대원이 탄 차량의 빈 좌석, 본부에 서 있는 빈 차량 가운데 골라 투입한다.
- **분대**: 나와 분대원 셋. 분대원 병과는 메뉴에서 고르고, 전투 중에도 분대 목표를 따라 움직인다.
- **난이도**: 쉬움(기본), 보통, 어려움. 적의 반응 속도, 조준 오차, 주고받는 피해가 달라진다.

## 병과

| 병과 | 하는 일 | 특성 |
| --- | --- | --- |
| 돌격병 | 앞장서서 거점을 뚫는다. 유탄·연막 유탄, 아드레날린·방탄판 | 체력이 더 빨리 차오른다 |
| 공병 | 대전차 로켓·대공 미사일로 차량을 잡고, 수리 도구·대전차 지뢰를 쓴다 | 내가 모는 차량이 스스로 고쳐진다 |
| 의무병 | 의무 가방, 탄약 상자, 연막탄. 쓰러진 아군을 일으킨다 | 누구든 1초 만에, 체력을 가득 채워 일으킨다 |
| 정찰병 | 드론·센서로 적을 찾고 비컨·클레이모어를 깐다 | 적 표시가 두 배 오래, 두 배 멀리 간다 |

로드아웃 화면에서 병과마다 주무기(11종 중 병과에 맞는 것), 조준경, 총구, 탄창, 손잡이, 장비 두 개를 고른다. 무기마다 위력·연사·사거리·조준·기동을 막대로 보여 주고, 부착물과 장비는 하는 일을 한 줄로 적어 둔다.

## 차량

주력전차, 보병전투차, 기동차량, 공격헬기. 좌석마다 맡는 무기가 다르고(운전석·포수석·기관총석), 장갑은 앞·옆·뒤로 두께가 다르다. 부서진 차량은 잠시 뒤 본부에서 다시 나온다.

## 전장

| 지도 | 성격 |
| --- | --- |
| 우엘렌 해안 | 항구 컨테이너와 어촌 골목의 보병전, 남쪽 들판의 전차전 |
| 암구에마 강 | 강을 가로지르는 다리 셋을 두고 다툰다 |
| 칸차란 정유 단지 | 창고와 컨테이너가 빽빽한 근접전 |
| 추코트카 설원 | 눈 덮인 평원과 숲, 레이더 기지를 사이에 둔 전차·헬기전 |

벽, 창문, 울타리, 모래주머니, 나무는 부서진다. 건물은 벽이 절반 넘게 무너지면 통째로 주저앉고, 그 안의 병사도 다친다. 연막은 시야를 가린다.

## 조작

**PC**: WASD 이동, 마우스 조준, 좌클릭 사격, 우클릭 정조준, R 재장전, Shift 달리기, C 앉기, 1 주무기, 2·3 장비, G 수류탄, Q 적 표시, E 탑승·하차·소생(누르고 있기), F 좌석 바꾸기, Space 연막·섬광탄(차량), Tab 점수판, M 지도, Esc 일시 정지.

**터치**: 화면 왼쪽을 끌어 이동, 오른쪽을 끌어 조준(끝까지 밀면 사격, 설정에서 자동 사격 끄기 가능), 오른쪽 버튼으로 정조준·재장전·수류탄·장비·앉기·표시·탑승. 터치 조준 보정 세기는 설정에서 바꾼다.

## 구조

```
src/game/    화면과 무관한 엔진 (정의, 격자 세계, 지도 생성, 길찾기, 전투, 차량, 봇, 프로필)
src/render/  캔버스 그리기 (지형 조각 굽기, 스프라이트, 파티클, 카메라)
src/ui/      화면 (메뉴, 로드아웃, 전투 HUD, 입력, 합성 효과음)
scripts/     한 장짜리 빌드, 화면 없는 전투 시뮬레이션
tests/       엔진 테스트
```

엔진은 60Hz 고정 간격으로 돌고, 렌더러는 엔진이 내보내는 사건(사격, 폭발, 붕괴 등)을 받아 효과를 그린다. 길찾기는 거점과 본부마다 거리장을 미리 구워 두고, 벽이 부서져 길이 열리면 그 부분만 다시 계산한다. 소리는 모두 Web Audio로 합성한다.
