# WarLine 3D

2147년 베링 해협, 미 북극사령부와 러시아 극동군의 정복전. 브라우저에서 도는 3D 1인칭 대규모 제병협동 슈터(Three.js, WebGL). 기본 32 대 32, 16 대 16과 64 대 64도 고를 수 있고, 아군과 적은 봇이 맡는다. PC(마우스·키보드)와 폰(터치) 모두 지원.

## 실행

```bash
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
npm run build:single   # 외부 파일 없이 열리는 한 장짜리 dist/warline.html
npm run typecheck
npx tsx scripts/sim.ts medium 10 0   # 화면 없이 봇끼리 10분 전투 (규모, 분, 지도 순번)
```

## 들어 있는 것

- **4병과**: 돌격병, 공병, 지원병, 정찰병. 병과별 장비 칸 2개와 투척 칸, 숙련 무기 보너스.
- **무기**: 주무기 19종(돌격소총, 카빈, 기관단총, 경기관총, 지정사수소총, 저격소총, 산탄총)과 권총 3종. 탄은 탄속과 낙차가 있는 투사체.
- **무기 커스텀**: 조준경, 총구, 총열, 하부, 탄창, 탄약, 개머리판 7칸. 부착물이 모델에 그대로 보이고, 수치 변화가 막대로 나온다.
- **장비 커스텀**: 로켓, 대공 미사일, 수리 토치, 대전차 지뢰, 유탄, 아드레날린, 접착 폭약, 의료·탄약 상자, 제세동기, 방벽, 드론, 감지기, 비컨, 클레이모어, 투척물 5종. 장비마다 변형 2~3개.
- **차량**: 주력전차, 보병전투차, 경전술차량, 공격 헬기. 좌석별 무기, 장갑 방향, 연막·플레어.
- **파괴**: 건물은 벽 판 단위로 부서지고, 벽을 많이 잃으면 무너진다.
- **정복전**: 거점 점령, 티켓, 쓰러짐과 소생, 분대 배치, 비컨 배치.

## 구조

`src/CONTRACT.md` 가 모듈 사이 규약이다. `src/types.ts`(공유 타입), `src/defs`(데이터), `src/world`(지형·건물·충돌·파괴), `src/sim`(규칙·이동·사격·장비·차량), `src/ai`(길찾기·봇), `src/render`(월드·인물·차량·1인칭 총기·이펙트), `src/ui`(메뉴·로드아웃·HUD·배치), `src/input`, `src/audio`, `src/app/battle.ts`(게임 루프).
